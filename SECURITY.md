# Security Policy

## Supported versions

Only the latest release receives security fixes. The project has not reached version 1.0, and no older release is
supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.

Report it privately through GitHub's private vulnerability reporting:
<https://github.com/jonatsu/virt-manager-mcp/security/advisories/new>

Include:

- Affected version, commit, or branch
- Steps to reproduce
- Impact and likely severity
- Any known workaround

## What happens next

The maintainers coordinate disclosure with you after a fix or mitigation is available.
